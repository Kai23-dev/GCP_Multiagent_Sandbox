# Gcp_Sandbox_Multiagent_Deployement
# Supplier Cost Optimization AI Agents  This project is a sandbox implementation of AI agents for Supplier Cost Optimization. The main idea is to use GenAI agents to analyze procurement and finance-related data from BigQuery and provide useful business insights.  I worked on setting up and testing agents like the Financial Leakage Agent and Trend Agent. The Financial Leakage Agent helps identify suspicious or unusual spend patterns, while the Trend Agent helps analyze spend changes across vendors, categories, and time periods.  The project uses Google Cloud Platform services such as BigQuery, Vertex AI/Agent Engine, Terraform, and Python. I also created and verified sandbox BigQuery datasets, handled Terraform setup, fixed authentication/certificate issues, and tested dummy data for agent validation.  This project helped me understand how multi-agent systems work in real-world enterprise use cases, especially how different agents interact with SQL generation, validation, execution, and cloud data sources.
